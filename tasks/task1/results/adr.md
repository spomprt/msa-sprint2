### <a name="_b7urdng99y53"></a>**Название задачи:**

Вынесение компонента работы с пользователями из монолита в отдельный микросервис

### <a name="_3bfxc9a45514"></a>**Функциональные требования**

| **№** | **Действующие лица или системы** | **Use Case**                | **Описание**                                                          |
|:-----:|:---------------------------------|:----------------------------|:----------------------------------------------------------------------|
|   1   | Пользователь                     | Бронирование                | Проверка дат, проверка доступности и оформление бронирования          |
|   2   | Пользователь                     | Поиск                       | Поиск отелей, просмотр информации                                     |
|   3   | Пользователь                     | Отзывы                      | Просмотр отзывов и возможность оставить свой                          |
|   4   | Пользователь                     | Промокоды                   | Получение и активация промокодов                                      |
|   5   | Монолит                          | Запрос на добавление брони  | Добавление брони в бд монолита с id пользователя из user-service      |
|   6   | Монолит                          | Поиск промокодов            | Добавление промокодов в бд монолита с id пользователя из user-service |
|   7   | Монолит                          | Запрос на добавление отзыва | Добавление отзыва в бд монолита с id пользователя из user-service     |

### <a name="_u8xz25hbrgql"></a>**Нефункциональные требования**

| **№** | **Требование**                                                |
|:-----:|:--------------------------------------------------------------|
|   1   | SLA доступности ≥ 99.9%                                       |
|   2   | Латентность API: p95 ≤ 100ms на чтение, p95 ≤ 200ms на запись |
|   3   | Пропускная способность с запасом X2-X3 от пиков               |
|   4   | Горизонтальное масштабирование                                |

### <a name="_qmphm5d6rvi3"></a>**Решение**

Диаграмма контекста

```puml
@startuml
!includeurl https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Context.puml

title Онлайн-платформа "Hotelio"

LAYOUT_WITH_LEGEND()

Person(user, "Пользователь", "Взаимодействует с системой")

System_Boundary(sys, "Онлайн-платформа для бронирования отелей и апартаментов") {
    System(hotelio, "Система", "Хранение данных, API")
}

Rel(user, hotelio, "Бронирование отелей, апартаментов")

@enduml
```

Диаграмма контейнеров

```puml
@startuml
!includeurl https://raw.githubusercontent.com/plantuml-stdlib/C4-PlantUML/master/C4_Container.puml
LAYOUT_WITH_LEGEND()

System_Boundary(central, "Платформа бронирования отелей и апартаментов") {
  Container(web, "Web Application", "React, HTML, CSS", "Позволяет просматривать отели, апартаменты")
  Container(monolith, "Hotelio Monolith", "REST", "Бронирование отелей, апартаментов, промокоды, работа с пользователями")
  ContainerDb(monolith_db, "Hotelio Monolith DB", "Relational DB", "База данных монолита")
  Container(user_service, "User Service", "REST", "Операции с пользователями")
  ContainerDb(user_db, "User Service DB", "Relational DB", "База данных сервиса пользователей")
}

Person(user, "Пользователь", "Бронирует отели и апартаменты")

Rel(user, web, "Использует", "HTTPS")
Rel(web, monolith, "Бронирование отелей, апартаментов, отзывы", "REST/JSON")
Rel(web, user_service, "Получение профиля, информации о пользователе", "REST/JSON")
Rel(monolith, monolith_db, "Читает и пишет", "JDBC")
Rel(monolith, user_service, "Получение информации о пользователе", "REST/JSON")
Rel(user_service, user_db, "Читает и пишет", "JDBC")

@enduml
```

### <a name="_bjrr7veeh80c"></a>**Альтернативы**

- Использовать асинхронный формат взаимодействия между монолитом и сервисом пользователей

**Недостатки, ограничения, риски**

- Возникают риски с сетевыми задержками и надежностью
- Если не использовать механизмы для обеспечения консистентности данных (например Saga), то возникнут проблемы
- Увеличиваются затраты на инфраструктурные задачи
